# CV-Responsive-Web
This website acts as an introduction to potential employers, at the end of the website, visitors can send me a message thorugh a form that is connected to a firebase.
As my first non academic project, this was a very fun one. I learned a lot about Web Development without any formal education. 
Developed using vanilla html css js as part of an individual assessment for Bina Nusantara Computer Club certification.

### Features
- Landing Page
- Navigation Bar
- Animation
- Fully Responsive Layout
- Real time Database integration
